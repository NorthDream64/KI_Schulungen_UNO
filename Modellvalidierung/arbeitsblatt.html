★Transfer · deine Fragen als KI-Manager:in

Du wirst diese Werte nie selbst rechnen. Formuliere drei Fragen, die du dem Entwicklungsteam stellst, bevor ein Modell in Betrieb geht:

Für Dozent:innen — erwartete Beobachtungen (nicht austeilen)

  • Station 1: Schwelle 0,05 → Precision ~47 % / Recall ~98 %; 0,50 → ~77 % / ~66 %; 0,95 → ~97 % / ~12 %. Trade-off: streng = wenige Fehlalarme, aber viele Übersehene. Recall zählt bei Betrug (Übersehen teuer), Precision bei Spam (Fehlalarm teuer). F2 < F1 hier, weil der Recall (66 %) schwächer ist als die Precision.
  • Station 2 (Schwelle 0,50): Auswahlrate Männer ~41 % vs. Frauen ~25 % (Lücke ~16 Pp.); Recall ~72 % vs. ~59 %. Ursache: die historischen Labels waren voreingenommen — das Modell lernt sie. Die Lücke bleibt auf jeder Schwelle.
  • Station 3: mit Geschlecht ~+16 Pp.; ohne Geschlecht ~+9 Pp. (bleibt!); ohne Geschlecht + Karrierelücke ~0. Proxy = ein Merkmal, das ein sensibles verrät (hier: Karrierelücke ↔ Geschlecht). Fairness durch Wegschauen scheitert.
  • Station 4: Tiefe 2 → Under (Training ~78 %, Test ~76 %, beide niedrig); Tiefe 4 → Sweet Spot (~81 % / ~77 %, nah beieinander); Tiefe 8 → Over (~92 % / ~74 %, große Lücke = auswendig gelernt).
  • Transfer: z. B. „Welche Metrik ist für unseren Fall die richtige — Recall oder Precision?", „Wie sind Precision/Recall je Gruppe?", „Wie groß ist die Lücke zwischen Trainings- und Testleistung?"
