# Deep Learning

**Begriff:** Deep Learning (Tiefes Lernen)

**Definition:** Deep Learning ist eine Unterform des Machine Learning, die mit künstlichen neuronalen Netzen arbeitet — Schichten von mathematischen Verarbeitungsstufen, die grob dem menschlichen Gehirn nachempfunden sind. Es eignet sich besonders für komplexe Eingaben wie Bilder, Sprache und Text.

---

**Typisches Problem ohne diesen Ansatz:**
Ein Automobilzulieferer prüft Metallbauteile auf Oberflächenfehler. Bislang schauen Mitarbeitende jedes Teil manuell an einem Förderband an — mit einer Fehlerquote von ca. 3 % und einem erheblichen Engpass bei hohem Produktionstempo. Kleinste Risse oder Einschlüsse sind mit bloßem Auge kaum zu erkennen.

**Wie der Ansatz das Problem löst:**
Ein Deep-Learning-Modell wird mit Tausenden von Fotos trainiert: fehlerfreie Teile und Teile mit bekannten Defekten, jeweils aus mehreren Winkeln. Die neuronalen Netze lernen selbstständig, welche Bildmuster auf einen Fehler hindeuten — auch solche, die einem Menschen nicht auffallen würden. Eine Kamera am Band fotografiert jedes Teil, das Modell klassifiziert es in Millisekunden.

**Konkretes Praxisbeispiel im Unternehmenskontext:**
BMW und Bosch setzen Deep-Learning-basierte Bilderkennungssysteme in der Qualitätssicherung ein. Die Fehlerquote sinkt auf unter 0,1 %, der Durchsatz steigt, und die manuelle Prüfung konzentriert sich auf Grenzfälle, die das System zur Überprüfung markiert.

**Häufiger Irrtum:**
Deep Learning braucht sehr große Mengen an Trainingsdaten und erhebliche Rechenleistung. Es ist nicht für jedes Problem das richtige Werkzeug — für strukturierte Tabellendaten oder kleine Datensätze ist klassisches Machine Learning oft überlegen und deutlich günstiger.
