# Instruktionen für die Erstellung eines Videos auf NotebookLM

Erstelle eine ca. 90-sekündige Einführung für Kursteilnehmende (KI-Manager im Unternehmenskontext, keine technischen Vorkenntnisse vorausgesetzt). Gliedere strikt in drei Akte: (1) Situation — schildere eine konkrete, wiedererkennbare Alltagssituation im Unternehmen, die ein typisches Problem zeigt. Kein Fachvokabular in diesem Abschnitt. (2) Mögliche Lösung — führe den Begriff ein und erkläre intuitiv, wie er das Problem adressiert. Verwende eine Analogie. (3) Auflösung — zeige das konkrete Ergebnis: Was hat sich geändert? Was kann der Manager jetzt anders entscheiden? Schließe mit einer offenen Frage, die Neugierde weckt. Ton: direkt, klar, kein Marketing-Jargon. Sprache: Deutsch, Du-Form.

Für schwieriger abzugrenzende Begriffe (z.B. Halluzination vs. Fehler):

Füge zwischen Situation und Lösung einen kurzen "Was es NICHT ist"-Einschub ein: maximal zwei Sätze, die einen häufigen Irrtum direkt adressieren.
