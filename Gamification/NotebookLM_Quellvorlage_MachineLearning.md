# Machine Learning

**Begriff:** Machine Learning (Maschinelles Lernen)

**Definition:** Machine Learning ist ein Teilgebiet der Künstlichen Intelligenz, bei dem Systeme aus Daten Muster erkennen und daraus eigenständig Schlussfolgerungen ziehen — ohne dass jemand explizit Regeln programmieren muss.

---

**Typisches Problem ohne diesen Ansatz:**
Ein Logistikunternehmen möchte voraussagen, welche Sendungen sich voraussichtlich verzögern werden. Bislang schaut ein Team täglich manuell auf Wetterdaten, Fahrzeugauslastung und historische Routen — ein zeitaufwändiger Prozess, der trotzdem viele Verzögerungen erst erkennt, wenn es zu spät ist.

**Wie der Ansatz das Problem löst:**
Ein Machine-Learning-Modell wird mit historischen Lieferdaten trainiert: wann haben sich Sendungen verzögert, unter welchen Bedingungen, auf welchen Routen? Das Modell erkennt selbstständig Muster, die kein Mensch bewusst formuliert hätte — und gibt täglich automatisch eine Risikoeinschätzung für alle laufenden Sendungen aus.

**Konkretes Praxisbeispiel im Unternehmenskontext:**
DHL und ähnliche Logistiker nutzen ML-Modelle, um Verzögerungsrisiken in Echtzeit zu bewerten. Disponenten erhalten automatisch Warnhinweise und können proaktiv umrouten oder Kunden informieren — bevor die Verzögerung eintritt.

**Häufiger Irrtum:**
Machine Learning "denkt" nicht. Es erkennt statistische Muster in vergangenen Daten. Wenn sich die Realität grundlegend ändert (z. B. eine neue Zollregulierung), muss das Modell mit neuen Daten neu trainiert werden — es lernt nicht automatisch weiter.
